# Sudheer Divyakolu — Portfolio

A simple, elegant, dependency-free portfolio built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploy to GitHub Pages

1. Create a repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your site will be available at:

`https://sudheerdivyakolu.github.io/portfolio/`

For a personal domain/repository, GitHub Pages can also use a `CNAME` file.

## Deploy to Vercel

Import the repository into Vercel. No build command or framework configuration is required.

## Before publishing

Replace the placeholder LinkedIn URL in `index.html` with your actual LinkedIn profile URL.

The project intentionally uses no build system, so the same source works on GitHub Pages and Vercel.
